# ADR-0003：关系入库必须经过审核

日期：2026-09-28 · 状态：已接受

## 背景

关系数据有三个来源：种子数据（人工整理）、LLM 挖掘、众包提交（`POST /api/relationships`。
LLM 产出存在幻觉风险，众包存在质量风险；默认图谱视图直接消费关系数据。

## 决策

- 关系存储只用规范方向：逆关系（`CHILD_OF`/`SERVANT_OF`/`STUDENT_OF`）入库时翻转归一化。
- **LLM 与众包来源的关系一律 `status=pending`**，不进入默认视图；
  经 `/api/review/*` 审核工作流（可选 `X-Review-Token` 鉴权）人工批准后才转为 `approved`。
- LLM 产出附带 `confidence` 与 `evidence` 字段，供审核时参考。

## 后果

- 正面：默认视图质量可控；每条关系可溯源。
- 代价：新增关系需要人工审核环节；批量挖掘后审核队列可能积压（看板 `/stats` 可监控）。
